# 🏫 SisDB - Educational Institute Management API

A robust and secure backend Web API designed for private educational institute management. Built with clean architecture principles to handle core institutional operations efficiently.

## 🚀 Features

* 🔐 **Authentication & Authorization:** Secure login and Role-Based Access Control (RBAC) using JSON Web Tokens (JWT).
* 📚 **Academic Management:** Comprehensive handling of students, classes, quizzes, and attendance records.
* 🏛️ **Clean Architecture:** Developed following a structured 3-Tier Architecture approach for clear separation of concerns.
* 🗄️ **Data Integrity:** Utilizes Entity Framework Core with LINQ for efficient and safe database operations.

---

## 🛠️ Tech Stack

* **Language:** C#
* **Framework:** ASP.NET Core (.NET 8)
* **ORM:** Entity Framework Core
* **Database:** Microsoft SQL Server
* **Security:** JWT (JSON Web Tokens), BCrypt / ASP.NET Core Identity
